# AI Attribution

## Mandatory Header

All AI-generated content posted to external systems (Jira, Confluence, GitLab, etc.) must start with:

```markdown
---
🤖 **AI-Generated Content**
- **Model**: [Model Name]
- **IDE**: [IDE Name]
- **Context**: [Reason]
- **Generated**: [ISO Timestamp]
---
```

## Compact Header

For short comments: `🤖 _AI-assisted_ - [Context]`

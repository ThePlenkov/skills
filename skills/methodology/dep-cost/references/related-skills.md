# Related skills

- `token-rationalism` (Tier 0) — Rule 8 (reuse before write) covers "use the dep"; this covers "is the dep worth it".
- `reuse-first` (Tier 2, sibling) — finds candidates; this one judges whether to keep them.
- `modern-stack` (Tier 2) — checks current supported version line for the dep.
- `security-and-hardening` (Tier 2) — CVE and supply-chain surface of the dep.
- `performance-investigation` (Tier 2) — overall app perf, of which deps are one input.
- `evidence` (Tier 2) — every claim in this skill must be backed by a measurement, not a hunch.
- `minimal-root-cause` (Tier 2) — the philosophy this operationalizes.
- `subagents-setup` — for delegation boundaries when this skill orchestrates work.
- `shared-plan` — for shared planning when this skill orchestrates work.

## Deprecation

There is no dedicated deprecation skill. When a dep is unmaintained, plan the deprecation and migration manually.

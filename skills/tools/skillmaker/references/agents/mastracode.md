## Notes

Mastra Code also provides `/github` for GitHub PR signals; it is not reserved here because `github` is already used by the `integrations/github` skill. Custom skills are loaded from `.mastracode/skills/`, `.agents/skills/`, and `~/.mastracode/skills/`.

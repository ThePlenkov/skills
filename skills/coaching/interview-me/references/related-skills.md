# Related skills

- `idea-refine` — downstream. If the confirmed intent is "I want X but I don't know how to scope it," generate variations against the now-explicit intent.
- `spec-driven-development` — downstream. If the confirmed intent is concrete ("I want X for Y users with Z success criteria"), write the requirements down.
- `shared-plan` — two hops downstream of this skill (after the spec).
- `critical-thinking` — opposite end of the timeline. Interview-me is pre-decision intent extraction; critical-thinking is post-decision artifact review. Both catch divergence, but at different moments.
- `external-research` — orthogonal. Interview-me clarifies what the user wants; external-research verifies framework facts. They don't compete.
